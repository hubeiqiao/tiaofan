# Built with GPT Sites

The entire Tiaofan website was built with GPT Sites through iterative prompting, implementation and testing. This description reflects the creator's account of the project's build process.

## The workflow

The product evolved through repeated rounds of product direction, interface implementation, source and behavior checks, and refinements to the live experience. The resulting application uses React and TypeScript, Vinext/Vite, Cloudflare Workers tooling and structured data adapters.

The source repository is a reviewed export of that work, adapted into a standalone example with synthetic records, neutral artwork and disabled private integrations. It is not a dump of the hosting platform's credentials, production database or deployment history.

- GPT Sites was the environment and workflow used to create and iterate on the website.
